# Folio inclusif — Charte graphique

Flipbook interactif présentant la charte graphique de **Folio inclusif**, une refonte inclusive de la collection Folio des éditions Gallimard.

## Technologies

- HTML / CSS / Vanilla JavaScript
- [StPageFlip](https://nodlik.github.io/StPageFlip/) — librairie open source pour l'effet de page

## Aperçu en ligne

→ [Voir le flipbook](https://VOTRE-USERNAME.github.io/folio-inclusif/)
